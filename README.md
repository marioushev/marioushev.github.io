# Good Studio

We are a product team building web apps, mobile apps, and UI/UX design — one group covering every layer of the product, from first prototype to App Store launch.

This repository hosts our portfolio site, a single-page overview of what we do and a selection of our work.

## What we do

- **Web Development** — React, TypeScript, and modern tooling
- **Mobile Apps** — native and cross-platform for iOS and Android
- **UI/UX Design** — research, design systems, and prototypes

## Structure

- `index.html` — the site (hero, services, tech stack, and Web / Mobile / Design work tabs)
- `assets/` — styles, scripts, fonts, and images
- `projects/` — self-contained project demos linked from the work section
